# Image Restoration

## Project Overview

This project implements an image restoration system designed to restore degraded input images and generate high-quality restored images. The project contains the complete training and inference workflow, trained model weights, evaluation script, restored test outputs, and the required Python dependencies. The repository is organized so that a reviewer can clone the repository, install the required dependencies, load the trained model, run the evaluation script on the test images, and obtain the restored output images without requiring manual modifications to the source code.

## FPGA / HLS Implementation

An FPGA-oriented implementation of the restoration model is also included in the project.

The HLS top-level function is:

restoration_top

The implementation contains the image restoration pipeline and the required memory interfaces for hardware execution.

The restoration pipeline consists of the following major stages:

Input → Head → RES1 → Expand → RES2 → Reduce → Upsample → RES3 → Tail → Final Output

The high-resolution restoration stages operate on the upsampled feature representation. The HLS implementation uses quantized data representations and memory interfaces required for hardware implementation.

The generated HLS IP can be integrated into the corresponding Vivado block design for FPGA implementation.
